# 会話画面

対応宣言: https://github.com/pupuchan1/future-company/issues/67

実装方針: https://github.com/pupuchan1/future-company/issues/69

## 動作

- ホームの開始ボタンから接続が成功すると `/conversation` に移動します。準備中・失敗時にはホームを維持します。
- 会話画面では、あなた・AI・お知らせを区別して文字起こしを表示します。途中の発言は同じ項目で更新され、確定すると途中表示が消えます。
- 最新ホームと同じ資料由来のロゴ・ブランド色（濃紺 #12293b、青緑 #00757d）を使います。デスクトップは音声オーブ・操作を左、会話履歴を右に配置し、スマートフォンはこの順で縦に並べます。
- 文字起こしには既存の `LiveSnapshot.transcripts` を使います。接続を管理するフックは画面移動でアンマウントされず、ホームとの往復や戻る／進むでは通話の開始・停止を呼びません。
- 下端では新しい発言に追従します。読み返し中は位置を保ち、「最新の会話へ」で追従を再開します。
- 会話終了後も現在の履歴を表示します。「新しい会話を用意する」でリセットしてホームに戻ります。
- 再読み込みやタブを閉じた後の復元・過去セッションの保存や検索は含みません。既存の音声接続・認証の動作を使います。

## 検証

```sh
npm run typecheck:frontend
npm exec --workspace frontend -- tsc -p tests/tsconfig.fixtures.json
npm run test:frontend
npm run lint
npm run build:frontend
```

ブラウザーでの表示・遷移確認には、開発サーバーの `/tests/fixtures/conversation.html` を使用できます。このページはマイクや接続APIを使わず、実際のページビューへテスト状態を渡す開発用フィクスチャーです。本番ビルドの入口には含みません。

1. 「AIに話しかける」で準備中になり、まだ画面が変わらないことを確認。「接続失敗」でもホームを維持。
2. 再度開始し、「接続成功」で `/conversation` への遷移と見出しへのフォーカスを確認。
3. 「発言を受信」「回答を確定」で話者・途中回答・確定文の表示を確認。
4. ホームとの往復、ブラウザーの戻る／進むでも履歴と開始・終了回数が変わらないことを確認。
5. 発言を繰り返し受信し、履歴を上にスクロール。新しい発言で位置が動かず、「最新の会話へ」で下端へ戻ることを確認。
6. 会話終了後も文面が残り、新しい会話を用意するとホームに戻って履歴が消えることを確認。
7. 日英表示、320px・390px幅で横スクロールがないことを確認。

実音声でのエンドツーエンド確認には、既存の音声・MCP接続の設定が必要です。フィクスチャーの会話は実音声の成功を示しません。
