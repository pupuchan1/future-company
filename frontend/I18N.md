# 日本語・英語の言語選択

ヘッダーのセレクターで `日本語` / `English` / `自動 / Auto` を選択する。画面表示・タイトル・読み上げ用の言語と、音声会話の希望言語に反映する。手動選択はブラウザーへ保存される。

- 手動選択は会話開始時の `language_preference: ja|en` として送る。開始の `language` も選択に合わせる。
- 会話中は `POST /api/live/session/:id/language` に `{case_id, language, language_preference}` を送る。同じ音声接続とcaseを維持し、マイクを取り直さない。
- 手動選択中は自動の言語分類で上書きしない。担当交代・人間回答の説明にも現在の希望言語を引き継ぐ。
- 自動の画面表示はブラウザーの優先Localeに従い、会話は発話に応じて判定する。自動への変更もサーバーへ伝え、手動固定を解除する。
- 変更は直列に送信し、素早く切り替えた場合は最後の選択を適用する。失敗しても会話は終了させず、言語変更の再試行ボタンを表示する。
- 対象case・active sessionを検証する。公開proxyも同じ案件の認可とsession所有権を検証して `/session/:id/language` を中継する。

過去の文字起こしや担当者の回答は原文で保持する。対応言語は日本語・英語。他言語の翻訳・音声品質は未検証。

UIとサーバーの回帰試験、模擬デバイス/APIによるブラウザー試験で、英語開始・会話中の切替・自動復帰・取消後の遅延応答・案件分離・再試行を確認する。実マイクとプロバイダーの英語音声往復は別途確認が必要。
